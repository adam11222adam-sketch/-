# تطبيق طلبات شي إن — وسيط التسوق والمساعدة في الطلب لليمن 🛍️

تطبيق أندرويد (Android Kotlin) احترافي، متكامل وعالي الأداء تم بناؤه باستخدام **Jetpack Compose** و **Material Design 3** وفق أحدث بنية برمجية معتمدة من Google (MVVM architecture). 

يقوم التطبيق بدور وسيط تسوق تفاعلي مستقل ومريح. يتيح للمستخدمين وخصوصاً في اليمن تصفح موقع شي إن (Shein) الرسمي العربي، واختيار منتجاتهم المفضلة، وحفظ المقاس واللون والكمية في سلة محليّة آمنة ومرتبة، وتوليد الفاتورة والطلبية بصيغة نصية مشفرة ومنسقة، ثم إرسالها فورًا بلمسة زر إلى رقم مندوب المحل المباشر عبر تطبيق واتساب لتسهيل الشحن والدفع وتتبع الطرود.

---

## ✨ المميزات الرئيسية للمشروع

1. **متصفح ذكي ومدمج (Internal WebView WebView Launcher):** تصفح آمن وسلس لمنتجات وموقع شي إن العربي بكامل مزاياه، مع شريط تحكم مرن للرجوع والتحديث والفتح الخارجي وتتبع فوري مؤشر التحميل.
2. **إضافة بلمسة واحدة (Floating Simple Add Drawer):** زر عائم تفاعلي عالي التباين أسفل المتصفح يقوم بقراءة رابط ومحتوى صفحة المنتج الحالية ويفتح فورًا نافذة منبثقة (Bottom Sheet) لإدخال الخصائص كاللون والمقاس وسعر القطعة مع إرفاق لقطة شاشة اختيارية.
3. **تنبيهات ذكية لضمان سلامة الروابط:** إذا حاول المستخدم الضغط على زر الإضافة وهو في الصفحة الرئيسية أو صفحة عامة، يقوم التطبيق بتنبيهه فوراً لتصفح منتج محدد تفاديًا لإضافة روابط عامة غير دقيقة.
4. **استقبال الروابط الخارجية (Share Intent Interceptor):** إمكانية مشاركة روابط المنتجات من متصفح الهاتف الخارجي أو من تطبيق شي إن الرسمي ومشاركتها مباشرة مع هذا التطبيق، حيث تفتح نافذة الإضافة تلقائياً ويتم ملء الرابط دون مجهود يدوي.
5. **سلة تجميع المشتريات المحلية (Room Database Cart Engine):** قائمة تفاعلية بجميع الإضافات تمكن المستخدم من تعديل المقاس، اللون، زيادة أو تقليل كمية القطع، المسح، أو تصفح الرابط مجدداً، مع حساب فوري لعدد القطع والمبلغ الإجمالي التقريبي والعملات.
6. **سجل الفواتير والطلبات السابقة (Sequential History Logs):** بمجرد فتح واتساب وتأكيد العميل على إرسال الطلبية، يقوم التطبيق بتسجيل كود تسلسلي فريد للفاتورة بالنمط المهني `SH-20260607-0001` وحفظها في المشتريات السابقة مع خيار الاسترجاع الفوري للمنتجات إلى السلة الحالية أو معاودة الإرسال.
7. **إدارة الملف الشخصي والعناوين:** شاشات مرتبة لإدخال الاسم الكامل، رقم الهاتف اليمني، المدينة، وموقع الشحن بالتفصيل ويتم حفظها تلقائيًا في ذاكرة المحاذاة المشتركة لتسريع الطلبيات المستقبلية.
8. **الأمان وحفظ الخصوصية المطلق (Offline-First Safety):** لا يقوم التطبيق بتخزين أي كلمات مرور أو جمع بيانات بطاقة الدفع البنكية أو تتبع ملفات الكوكيز، فجميع البيانات والملفات والصور تحفظ مشفرة محلياً بالكامل داخل جوال المستخدم دون الحاجة أو الاستعانة بأي خوادم خارجية سرية.

## 🛠️ المكتبات والتقنيات المستخدمة (Technical Stack)

* **لغة البرمجة الأساسية:** Kotlin (100% Native Android application).
* **واجهات المستخدم الرسومية:** Jetpack Compose (Modern Material Design 3 UI).
* **إدارة وتوزيع الحالة:** ViewModel & StateFlow (MVVM Architectural Pattern) المجمع مع Flow التفاعلي.
* **قاعدة البيانات المحلية:** Room Database (لحفظ السلة وسجل الطلبات السابقة).
* **تخزين الإعدادات المدمجة:** Android Preferences (لحفظ بيانات العميل وإعدادات التطبيق الهيكلية).
* **تحميل وعرض الصور المدمجة:** Coil Compose (لجلب ومعاينة لقطات الشاشة والصور الملحقة).
* **تبادل واستلام المشاركة:** Android ACTION_SEND Intent Filters (لاستقبال نصوص الروابط المشتركة من الخارج).

## 🏗️ الهيكل التنظيمي للمشروع (Project Architecture)

يتبع التطبيق تصنيفاً منظماً يسهل التعديل والتوسيع:

```text
app/src/main/java/com/example/
  ├── core/
  │    ├── constants/   <-- الثوابت المدمجة والافتراضية (AppConfig.kt)
  │    ├── services/    <-- إدارة الذاكرة المحلية والأوامر التفاعلية (PreferencesManager.kt)
  │    └── theme/       <-- الألوان وخامات التصميم النسائي الهادئ (Color.kt, Theme.kt)
  ├── data/
  │    ├── local/       <-- جداول قاعده البيانات وجداول التفاعلات (AppDatabase.kt, CartItemDao.kt)
  │    ├── models/      <-- الهياكل ونماذج المعطيات (CartItem.kt, SavedOrder.kt)
  │    └── repositories/ <-- عزل وتبسيط طلبات المعطيات البرمجية (CartRepository.kt)
  ├── features/
  │    └── main/        <-- المنطق الرسومي لجميع الشاشات مجمعة بنسق RTL (MainViewModel.kt, MainScreen.kt)
  └── MainActivity.kt   <-- نقطة البدء التشغيلية واعتراض الروابط الخارجية
```

## ⚙️ التعديل والتخصيص (How to Customize)

### 1️⃣ تعديل رقم واتساب الافتراضي للمندوب
لتعديل رقم الهاتف الذي يتم إرسال طلبات التسوق إليه بشكل ثابت، افتح الملف الافتراضي التالي:
* الملف: `app/src/main/java/com/example/core/constants/AppConfig.kt`
* السطر: `const val DEFAULT_WHATSAPP_NUMBER = "967773793649"`
* قم بتغيير الرقم إلى رقم المندوب الجديد مع مراعاة كود الدولة (مثال: `967XXXXXXXXX`).

### 2️⃣ تعديل رابط موقع شي إن الافتراضي للتصفح
إذا رغبت في توجيه المستخدمين لفتح قسم محدد لشي إن أو تعديل النطاق:
* الملف: `app/src/main/java/com/example/core/constants/AppConfig.kt`
* السطر: `const val DEFAULT_SHEIN_URL = "https://ar.shein.com/"`
* قم بتوجيهه إلى الرابط المطلوب في موقع شي إن.

> **💡 ملاحظة تفاعلية:** يمكن للمستخدمين والمندوبين بسهولة تعديل وتخصيص رابط تصفح شي إن ورقم واتساب المندوب فوريًا من داخل واجهة التطبيق عبر تفعيل **تبويب الإعدادات -> تهيئة إعدادات الوسيط الخاصة** دون الحاجة لإعادة بناء التطبيق من جديد!

## 🚀 طريقة التشغيل والبناء (Building the APK)

تستطيع تجربة التطبيق وبناء نسخة التشغيل النهائية (APK) عبر الأندرويد ستوديو أو باستخدام سطر الأوامر:

### 1️⃣ طريقة تشغيل وبناء التطبيق محليًا (Local Debug)
يفضل استخدام أحدث نسخة من **Android Studio** لفتح وتنفيذ المشروع كـ Gradle Project.
1. قم بفتح المجلد الجذري للتطبيق داخل Android Studio.
2. انتظر ثوانٍ معدودة حتى يقوم Gradle بمزامنة الاعتمادات وتحميل ملفات الـ KSP لـ Room.
3. صل هاتف أندرويد حقيقي عبر ميزة تصحيح الأخطاء (USB Debugging) أو افتح المحاكي المدمج.
4. اضغط على زر التشغيل **Run** الأخضر لبدء التثبيت والمعاينة.

### 2️⃣ بناء ملف الـ APK النهائي للإنتاج (Production Bundle)
لبناء ملف التثبيت المستقل بأقل حجم تشغيلي ممكن مستخدمًا سطر الأوامر:

* للأنظمة التي تدعم Gradle:
  ```bash
  gradle assembleDebug
  ```
  سيعمل الأمر على تجميع الكود البرمجي وتصدير ملف التثبيت الجاهز تلقائيًا في المسار:
  `app/build/outputs/apk/debug/app-debug.apk`
